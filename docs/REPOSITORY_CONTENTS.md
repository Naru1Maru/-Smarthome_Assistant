# Состав публикационной версии репозитория

Эта папка содержит очищенную копию материалов, которые целесообразно публиковать на GitHub как программную часть ВКР.

## Включено

| Путь | Содержание |
| --- | --- |
| `android_app/` | Android-приложение для пользовательского взаимодействия с системой. |
| `ha_addon_dist/smarthome_gateway_next/` | Home Assistant add-on с сервером-шлюзом и основными модулями обработки. |
| `smarthome_core/smarthome_core/` | Основной Python-пакет: интерпретация команд, LLM-контур, сценарии, валидация, интеграция с Home Assistant. |
| `smarthome_core/smarthome_gateway/` | Серверный слой gateway. |
| `smarthome_core/schemas/` | JSON Schema для внутренних структур команд и сценариев. |
| `smarthome_core/lexicon/` | Словари и нормализационные данные для rule-based обработки. |
| `smarthome_core/registry/` | Тестовый реестр устройств и зон. |
| `smarthome_core/scripts/` | Скрипты для прогонов и расчёта экспериментальных метрик. |
| `smarthome_core/tests/` | Автоматизированные тесты Python-части и gateway. |
| `smarthome_core/data/` | Отобранные тестовые наборы команд и сценариев. |
| `docs/experiments/` | Сводные протоколы экспериментов, использованные в пятой главе. |
| `docs/thesis_figures/` | Схемы, подготовленные для текста ВКР. |

## Исключено

Из публикационной копии исключены IDE-настройки, сборочные артефакты, временные каталоги, виртуальные окружения, кэши Python/Gradle, рабочие логи, архивы сборок и локальные конфигурационные файлы.

Полный текст ВКР не включён в репозиторий. В папке `docs/` оставлены только материалы, полезные для понимания состава проекта, воспроизводимости экспериментов и связи программной реализации с результатами работы.

## Проверка перед публикацией

Перед созданием публичного репозитория нужно дополнительно проверить:

1. В файлах отсутствуют реальные токены Home Assistant, API-ключи и пароли.
2. В конфигурации используются примерные значения, а не адреса локальной сети автора.
3. Файл `android_app/local.properties` отсутствует.
4. Каталоги `build`, `.gradle`, `.idea`, `.venv`, `__pycache__` отсутствуют.
5. Сырые модели LLM и файлы формата `.gguf` не добавлены в репозиторий.
